# Mergington High School Activities

A website application that allows students to view and sign up for extracurricular activities, and enables teachers to manage student registrations.

## Features

- View all available extracurricular activities with descriptions, schedules, and participant counts
- Filter activities by category (Sports, Arts, Academic, Community, Technology)
- Filter activities by day of the week (Monday through Sunday)
- Filter activities by time of day (Before School, After School, Weekend)
- Search activities by name
- Group activities by category
- Teacher login to manage student registrations
- Sign up students for activities (requires teacher authentication)
- Unregister students from activities (requires teacher authentication)
- Persistent data storage using MongoDB
